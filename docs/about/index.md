# About

OpenStack 기반 프라이빗 클라우드 구축·운영을 전문으로 하는 인프라 엔지니어.
이동통신망 엔지니어에서 출발해 NFV, OpenStack을 거쳐 현재 국책 프라이빗 클라우드 구축까지, 17년간 인프라 도메인을 연속적으로 심화해 왔다.
